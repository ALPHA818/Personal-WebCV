# Personal WebCV

An early visual shell for Hanre Bornman's interactive parchment CV.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```sh
python3 -m http.server 4173
```

The landscape environment is intentionally a CSS placeholder until final artwork is supplied. The content is sample copy intended to be replaced during the content-planning stage.

The rollers use a horizontal-cylinder rotation prototype. The position wrapper, supports, and axles stay fixed while the internal drum, stripe, marker, engraving, and connected end faces rotate around the left-to-right longitudinal axis. Rotation is derived from parchment travel divided by the measured drum radius.
